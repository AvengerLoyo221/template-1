# Mephisto Template

Template website personal bertema Pip-Boy. React + Vite, CSS biasa.

- `npm install` lalu `npm run dev` untuk menjalankan lokal
- `npm run build` untuk build produksi (hasil di `dist/`)
- `npm run lint` untuk cek kode

Cara mengubah isi:

- Daftar proyek: `src/data/projects.js`
- Teks Home dan About: `src/pages/`
- Nama brand dan menu navigasi: `src/App.jsx`
- Warna dan tampilan: `src/index.css`
